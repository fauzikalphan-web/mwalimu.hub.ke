# Mwalimu Hub KE V0.5 Final Handoff

## Included in this source
- Learner authentication and profile endpoints
- Curriculum, levels, subjects, topics and published lessons
- Lesson completion and learner progress endpoints
- Quiz retrieval, server-side scoring and results history
- Certificate listing endpoint
- Notifications endpoints
- Subscription history and M-Pesa checkout placeholder
- Admin user/analytics/content publishing endpoints

## Required before production
1. Configure PostgreSQL and run Prisma migrations/seed.
2. Set JWT_SECRET, DATABASE_URL, CORS_ORIGIN and production environment values.
3. Connect the M-Pesa Daraja callback/STK Push adapter and verify payment callbacks.
4. Complete mobile UI wiring for progress, quizzes, results and certificates.
5. Add automated tests, security review, backups and monitoring.
6. Build and sign Android APK/AAB using a cloud CI service or computer.
7. Deploy API/database and configure the mwalimu.hub.ke domain.

This is a source-code handoff. It is not a compiled or production-certified APK.
