# Mwalimu Hub KE V0.4 — Final learner increment

## Included
- Curriculum explorer: curriculum → level → subject → topic.
- Topic lesson listing and lesson reading view.
- Pull-to-refresh for curriculum and lessons.
- Existing API client with bearer-token support.
- Existing authentication, admin foundation, database schema and seed data.

## Release boundary
This package is source code. It has not been compiled into an APK/AAB or deployed from this environment.
Before production release:
1. Set the production API URL in `ApiClient`.
2. Run database migrations and seed only in development.
3. Add authenticated lesson-completion/progress endpoints and quiz UI if those endpoints are not present.
4. Test on a physical Android device.
5. Configure signing, privacy policy, M-Pesa production credentials, backups and monitoring.
6. Deploy the API and web app, then build and sign the Android release.

## Current limitation
The present V0.4 source exposes reading/navigation. Completion, progress, quiz, certificates and payments remain release-stage work unless implemented by the backend.
