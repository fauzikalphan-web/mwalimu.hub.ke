# Mwalimu Hub KE V0.3 Build Notes

Implemented in this iteration:
- Seedable starter Kenyan CBC/CBE curriculum data.
- Safe seeded admin account (change the seed password before production).
- Starter published Mathematics lesson and quiz for development/testing.
- Learner registration screen connected to the public learner-only registration API.
- Fixed Flutter logo asset placement/reference so the mobile project uses `assets/logo.png`.

## Seed
From `services/api`:

`SEED_ADMIN_PASSWORD='use-a-strong-development-password' npm run prisma:seed`

The seed creates `admin@mwalimuhub.ke` as an ADMIN and sample Grade 7 Mathematics content.
Do not use the default development password in production.
